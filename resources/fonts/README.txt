mitaltelipdfsymbol.* (TCPDF format, used for webtrees 2.0 - 2.2): one-glyph font used ONLY in PDF reports to draw U+26EE
(GEAR WITHOUT HUB), because the PDF font bundled with webtrees (DejaVu Sans) has no glyph for it.
For webtrees 2.3 the same glyph outline is embedded as a vector path in app/Report/MitalteliPdfRenderer_2_3.php.

Derived from "Noto Sans Symbols" (c) 2022 The Noto Project Authors, https://github.com/notofonts/symbols
(subset to U+0020 and U+26EE, then converted). Licensed under the SIL Open Font License 1.1, see
OFL-NotoSansSymbols.txt. MitalteliPdfSymbol-subset.ttf is the subset before the conversion.
